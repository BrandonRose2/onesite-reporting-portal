# Boca Ciega Delinquent and Prepaid Report Structure

The filed workbook has three worksheets. `Sheet1` is the management delinquency roll-up with a report heading, parameters, resident/unit detail rows, a totals row, and report legend notes. `Sheet2` contains a related resident detail listing. `Sheet3` contains transaction-level detail.

The renderer should present the report header and parameters as metadata, the totals row as summary metrics, the Sheet1 resident/unit rows as the primary management table, and the transaction-level sheet as secondary supporting detail. The original Excel remains a separate preserved source document.
